# Read this first (AI assistants)

This repo keeps its own memory so the owner never has to re-explain things.

1. Read `docs/ai/PROJECT_CONTEXT.md` (what the game is, branding, stack, rules).
2. Read `docs/ai/ROADMAP.md` (what is done, what is next).
3. Owner pushes via Termux: when git help is needed, use `docs/ai/TERMUX_GIT.md`.
4. Skim `docs/ai/DECISIONS.md` (why things are the way they are) and the last entries of `docs/ai/SESSION_LOG.md`.

**Before ending any session, you MUST:**
- Append an entry to `docs/ai/SESSION_LOG.md` (what was asked, what changed, what is unfinished).
- Tick or update items in `docs/ai/ROADMAP.md`.
- Add any new decision to `docs/ai/DECISIONS.md`.
- Update `PROJECT_CONTEXT.md` if branding, stack or rules changed.

Keep entries short and factual. Never store secrets (keys, passwords) in these files.
